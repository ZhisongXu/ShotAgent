# Archived 4KAgent restoration system

This directory contains the original NeurIPS 2025 4KAgent code, restoration
executors, profiles, evaluation scripts, assets, and installation instructions.

It was moved out of the project root when the repository was repurposed for the
BayesGrade / AnchorRetouchAgent research direction. No original tracked files
were deleted; the move is recoverable through Git history.

Paths and commands in the archived README are relative to this directory.
